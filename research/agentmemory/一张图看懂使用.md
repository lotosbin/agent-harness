## 核心操作

| 操作 | 命令/方法 | 说明 |
|------|----------|------|
| 安装 | `npm install @agentmemory/agentmemory` | npm 包安装 |
| 启动 | 自动启动（3111/3113 端口） | REST API + 实时查看器 |
| 接入 Agent | 配置 hooks | 自动捕获 Session 数据 |
| 存储记忆 | `mem::remember` | 添加到 Working Memory |
| 检索记忆 | `mem::search` | 三路混合检索 + RRF 融合 |
| 触发整合 | Session 结束自动触发 | Working → 四层记忆 |
| 导出数据 | `mem::export` | 备份或迁移 |

## 数据隐私

- **本地存储**：`~/.agentmemory/data/state_store.db`（SQLite）
- **本地嵌入**：all-MiniLM-L6-v2 模型，**无需 API key**
- **隐私过滤**：自动剥离 API keys 和 secrets 后存储
