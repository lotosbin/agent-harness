### 4. RRF 融合

```
┌──────────────────────────────────────────────┐
│         RRF (k=60) 融合公式                   │
│                                              │
│   RRF(d) = Σ  1/(k + rank(d))               │
│            ──────────────                    │
│              q∈Q路检索                       │
│                                              │
│   三路结果按排名融合，支持多样性打散          │
└──────────────────────────────────────────────┘

示例：三路分别返回
  BM25:   [A, B, C]
  Vector: [B, A, D]
  Graph:  [A, C, B]

融合后: A (rank 1+1+1), B (rank 2+2+3), ...
```

## 核心 API

### 存储类

| API | 功能 |
|-----|------|
| `mem::remember` | 添加到 Working Memory |
| `mem::consolidate` | 触发整合管道 |
| `mem::crystallize` | 结晶为持久化记忆 |
| `mem::compress` | LLM 压缩 |
| `mem::snapshot` | 快照 |
| `mem::export` | 导出数据 |

### 检索类

| API | 功能 |
|-----|------|
| `mem::search` | 三路混合检索 |
| `mem::bm25_search` | BM25 检索 |
| `mem::vector_search` | 向量检索 |
| `mem::graph_search` | 知识图谱检索 |
