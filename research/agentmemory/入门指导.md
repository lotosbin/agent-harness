# agentmemory 入门指导

## 前置要求

- Node.js 18+
- npm 或 Docker（可选）

## 安装步骤

### 方式一：npm 一键安装（推荐）

```bash
npm install @agentmemory/agentmemory
```

启动服务后自动占用：
- **3111** 端口：REST API
- **3113** 端口：实时查看器（WebSocket）

### 方式二：Docker

```bash
docker pull agentmemory/agentmemory
docker run -p 3111:3111 -p 3113:3113 agentmemory/agentmemory
```

### 方式三：MCP 工具模式（轻量级）

不启动完整服务器，使用 MCP 工具模式：

```bash
npx @agentmemory/mcp
```

## Agent 接入

### Claude Code

在项目根目录创建 `.claude/` 目录并配置 hooks（具体配置见官方 AGENTS.md）

### 其他 Agent

支持 Codex、Cursor、Windsurf、OpenCode、Cline、Gemini 等，参考各 Agent 的 hooks 配置方式。

## 快速验证

启动后访问：

- API 文档：http://localhost:3111/docs
- 实时查看器：http://localhost:3113

## 数据存储

默认存储路径：`~/.agentmemory/data/state_store.db`（SQLite）

## 可选：使用云端嵌入

如需使用 OpenAI 或 Cohere 嵌入，在环境变量中配置：

```bash
export OPENAI_API_KEY=your-key
# 或
export COHERE_API_KEY=your-key
```

默认使用本地 all-MiniLM-L6-v2 模型，无需配置。

## 基本使用示例

```javascript
import { AgentMemory } from '@agentmemory/agentmemory';

const memory = new AgentMemory();

// 存储记忆
await memory.remember({
  content: '用户在 /api/users 路径下发现了性能问题',
  type: 'observation',
  metadata: { sessionId: 'abc123', timestamp: Date.now() }
});

// 检索记忆
const results = await memory.search({
  query: '性能问题',
  limit: 5
});
```
