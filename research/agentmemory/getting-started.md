# agentmemory Getting Started

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                          agentmemory Quick Start                               │
└────────────────────────────────────────────────────────────────────────────────┘

  1. 安装
  ─────────────────────────────────────────────────────────────────────────────
  npx @agentmemory/agentmemory

  → 自动安装 npm 包
  → 启动服务器 (:3111 + :3113)
  → 引导式配置 API key

  2. 验证
  ─────────────────────────────────────────────────────────────────────────────
  curl http://localhost:3111/agentmemory/health

  3. 接入 Claude Code
  ─────────────────────────────────────────────────────────────────────────────
  agentmemory connect claude-code

  4. 运行 Demo
  ─────────────────────────────────────────────────────────────────────────────
  agentmemory demo
  # 灌入 3 个示例 session → 演示语义搜索

  5. 查看记忆
  ─────────────────────────────────────────────────────────────────────────────
  浏览器打开 http://localhost:3113
  # 实时查看器：观察记忆数据的写入变化

  6. 其他命令
  ─────────────────────────────────────────────────────────────────────────────
  agentmemory stop      # 停止服务器
  agentmemory doctor    # 诊断环境配置
  agentmemory upgrade   # 更新运行时
  agentmemory remove    # 卸载

  前置要求: Node.js ≥ 20
```
