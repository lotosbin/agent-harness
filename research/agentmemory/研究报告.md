# rohitg00/agentmemory 调研报告

## 1. 项目概述

**agentmemory** 是 AI 编程 Agent 的长期记忆框架，让 LLM 跨 Session 积累经验，解决大模型无状态问题。

- **作者**：rohitg00
- **版本**：v0.9.21（2026-05-20 最新发布）
- **开源协议**：Apache-2.0
- **GitHub**：14.3k+ Stars
- **定位**：AI 编码 Agent 的持久化记忆系统

## 2. 核心技术架构

### 2.1 三路混合检索引擎

| 检索方式 | 原理 | 特点 |
|----------|------|------|
| BM25 | 词干提取 + 同义词扩展 + CJK 分词 | 精确关键词匹配 |
| 向量检索 | all-MiniLM-L6-v2，384 维嵌入 | 语义相似性 |
| Graph 检索 | 实体 + 边的权重（0.1-1.0） | 关系发现 |

三路结果通过 **Reciprocal Rank Fusion (RRF, k=60)** 算法融合，兼顾精确匹配和语义理解，支持 Session 多样性打散。

### 2.2 四层记忆模型

```
Working Memory ──▶ Episodic Memory ──▶ Semantic Memory ──▶ Procedural Memory
  (原始观察)        (LLM 蒸馏压缩)       (实体抽取+索引)     (结构化知识沉淀)
```

- **Working Memory**：实时捕获的原始观察记录
- **Episodic Memory**：Session 结束时 LLM 蒸馏压缩后的记忆片段
- **Semantic Memory**：实体抽取 + BM25 索引构建
- **Procedural Memory**：结构化的知识沉淀

### 2.3 记忆整合管道

Session 结束时自动触发整合流程：Working Memory → Episodic Memory → Semantic Memory → Procedural Memory。整合过程内置**隐私过滤**，自动剥离 API keys 和 secrets。

核心函数：`mem::consolidate`、`mem::crystallize`、`mem::compress`、`mem::snapshot`、`mem::export`

## 3. 性能基准

在 LongMemEval-S（500 题）上测试结果：

| 指标 | 三路混合检索 | BM25-only | 提升 |
|------|-------------|-----------|------|
| R@5 | **95.2%** | 86.2% | +9% |
| MRR | **88.2%** | 71.5% | +16.7% |

## 4. 部署与接入

### 4.1 安装方式

```bash
npm install @agentmemory/agentmemory
```

安装后自动占用 3111（API）和 3113（实时查看器）端口。

### 4.2 支持的 Agent（15+）

Claude Code、Codex、Cursor、Windsurf、OpenCode、Cline、Gemini 等。

### 4.3 存储与隐私

- 数据存储在 `~/.agentmemory/data/state_store.db`（SQLite）
- 默认使用 all-MiniLM-L6-v2 本地向量模型，**无需外部 API key**（可选 OpenAI/Cohere 嵌入）
- 自动剥离 API keys 后存储，保护隐私

### 4.4 接口规模

- REST API：124 个端点
- MCP 工具：53 个
- 自动捕获钩子：12 个

## 5. 技术依赖

- **引擎**：依赖 iii-sdk（WebSocket 连接 iii-engine）
- **原语**：Worker、Function、Trigger 三种
- **向量模型**：all-MiniLM-L6-v2（本地，离线免费）
