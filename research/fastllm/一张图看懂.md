## 推理流程（以 DeepSeek R1 为例）

```
┌────────────────────────────────────────────────────────────────┐
│  用户请求: "解释量子计算"                                         │
│                        ↓                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  1. Tokenizer 编码 → input_ids                          │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  2. 稠密层 (Shared Expert) → CudaDevice (GPU)            │  │
│  │     Embedding / Attention / FFN / RoPE                     │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  3. MOE 层 (路由选择专家)                                  │  │
│  │     ┌─────────────────────────────────┐                   │  │
│  │     │ Router → Top-K 专家选择         │                   │  │
│  │     │ 专家1 ─┬─→ Expert FFN (CPU)     │                   │  │
│  │     │ 专家2 ─┼─→ Expert FFN (CPU)     │  ← NumaDevice    │  │
│  │     │ 专家3 ─┴─→ Expert FFN (CPU)     │                   │  │
│  │     │ Shared Expert → CudaDevice      │  ← CudaDevice   │  │
│  │     └─────────────────────────────────┘                   │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  4. 动态 Batch 合并 → 并发推理多个请求                    │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  5. Tokenizer 解码 → 流式输出 tokens                       │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  响应: "量子计算是一种利用量子力学原理..." (流式输出)            │
└────────────────────────────────────────────────────────────────┘
```

## 模型支持矩阵

```
模型系列        │ 支持情况                      │ 量化支持
───────────────┼───────────────────────────────┼──────────

Baichuan      │ ✅ Baichuan 1/2/3             │ FP16~INT4
MOSS          │ ✅ MOSS 系列                  │ FP16~INT4
Phi           │ ✅ Phi-1/2/3                  │ FP16~INT4
MiniCPM       │ ✅ MiniCPM 系列               │ FP16~INT4
MOE 模型       │ ✅ DeepSeek-MOE / Qwen-MOE   │ FP8~INT4
```

## 关键参数速查

```bash
# 最简部署
ftllm run Qwen/Qwen3-0.6B

# DeepSeek R1 671B 单卡部署
ftllm server deepseek-ai/DeepSeek-R1 --dtype int4 --device cuda --moe_device cpu

# 多卡张量并行
ftllm server model --device multicuda:0,1,2

# 混合精度
ftllm server model --dtype fp8 --moe_dtype int4

# API Server 启动
ftllm server model --port 8080 --api_key xxxxxxxx
```
