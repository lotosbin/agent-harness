# fastllm 入门指导

## 5 分钟快速上手

### 第 1 步：安装（1 分钟）

```bash
# Linux + NVIDIA GPU (推荐)
pip install ftllm -U

# 如果 pip 速度慢，换镜像
pip config set global.index-url https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
pip install ftllm -U

# Mac (仅 CPU)
pip install ftllm -U
```

> 首次安装会自动下载模型（约 1-3GB），可喝茶等待。

### 第 2 步：运行第一个模型（2 分钟）

```bash
# 命令行对话（最简单）
ftllm run Qwen/Qwen3-0.6B

# 或者启动 WebUI（浏览器访问）
ftllm webui Qwen/Qwen3-0.6B

# 或者启动 API Server（供应用调用）
ftllm server Qwen/Qwen3-0.6B --port 8080
```

安装成功会看到类似输出：

```
ftllm version: 0.x.x
Loading model: Qwen/Qwen3-0.6B
Model loaded successfully.
> 你好
Hello! I'm Qwen, a large language model... (流式输出)
```

### 第 3 步：部署 DeepSeek R1 671B（3 分钟）

```bash
# 方式一：直接在线量化部署（最简单）
ftllm server deepseek-ai/DeepSeek-R1 --dtype int4 --device cuda --moe_device cpu

# 方式二：预导出量化模型（加载更快）
ftllm download deepseek-ai/DeepSeek-R1
ftllm export /本地路径/DeepSeek-R1 -o /本地路径/DeepSeek-R1-INT4 --dtype int4 -t 16
ftllm server /本地路径/DeepSeek-R1-INT4

# 方式三：多卡加速
ftllm server deepseek-ai/DeepSeek-R1 --dtype fp8 --device multicuda:0,1
```

### 第 4 步：API 调用（可选）

```bash
# 启动服务
ftllm server Qwen/Qwen3-0.6B --port 8080 --api_key mysecret

# 调用示例
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer mysecret" \
  -d '{
    "model": "Qwen/Qwen3-0.6B",
    "messages": [{"role": "user", "content": "用一句话解释量子纠缠"}],
    "max_tokens": 200,
    "stream": true
  }'
```

## 常见问题

### Q: 安装报错 "ftllm 加载报错"
**A:** 参考 [FAQ 文档](https://github.com/ztxz16/fastllm/blob/master/docs/faq.md#ftllm加载报错)，或尝试：
```bash
# conda 环境问题，换虚拟环境
python -m venv venv
source venv/bin/activate
pip install ftllm -U
```

### Q: CUDA 不可用
**A:** 检查 CUDA 安装：
```bash
nvcc --version        # 查看 CUDA 版本
nvidia-smi            # 查看 GPU 状态
pip install ftllm -U  # 重新安装（pip 会自动检测 CUDA）
```

### Q: DeepSeek R1 显存不够
**A:** 使用 INT4 量化 + CPU 混合推理：
```bash
ftllm server deepseek-ai/DeepSeek-R1 --dtype int4 --device cuda --moe_device cpu
# 显存只需 >10G，MOE 层交给 CPU
```

### Q: 如何下载模型到本地
```bash
ftllm download deepseek-ai/DeepSeek-R1
# 模型默认保存到 ~/.cache/huggingface/hub/
```

### Q: 推理速度慢
**A:** 尝试以下优化：
```bash
# 1. 换更高精度（可能反而更快）
ftllm server model --dtype fp16 --device cuda

# 2. 多线程 CPU 推理
ftllm run model -t 27

# 3. 多卡并行
ftllm server model --device multicuda:0,1
```
