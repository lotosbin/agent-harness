# 一张图看懂 keep-codex-fast 使用

## 使用流程图

```
┌─────────────────────────────────────────────────────────────┐
│                        开始                                  │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 只读检查（Inspect）                                  │
│  python keep_codex_fast.py                                   │
│                                                             │
│  ✅ 不写任何文件                                              │
│  ✅ 不移动任何内容                                            │
│  ✅ 默认输出伪匿名数据                                        │
│  ✅ 可用 --details 显示详细信息                               │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
                  ┌─────────────────┐
                  │  Codex 感觉变慢？│
                  └────────┬────────┘
                           │ 有
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 为重要仓库会话创建交接文档（Handoff Docs）           │
│                                                             │
│  ✅ 记录当前目标、已完成工作、涉及文件                        │
│  ✅ 记录已运行命令、已知问题                                 │
│  ✅ 包含重新激活提示语（Reactivation Prompt）                │
│  ✅ 保存到 docs/codex-handoffs/YYYY-MM-DD-topic.md          │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 备份（Backup Only）                                │
│  python keep_codex_fast.py --backup-only                   │
│                                                             │
│  ✅ 备份到 ~/Documents/Codex/codex-backups/                │
│  ✅ 不移动原始文件                                           │
│  ✅ 不修剪元数据                                             │
└─────────────────────────┬───────────────────────────────────┘
                          ▼

│                                                             │

                          ▼
┌─────────────────────────────────────────────────────────────┐

│  ✅ 确认 log size 减少                                      │

                          ▼

└─────────────────────────────────────────────────────────────┘
```

## 三种模式对比

| 特性 | Inspect（默认） | Backup Only | Maintain（Apply） |
|------|:--------------:|:-----------:|:-----------------:|
| 报告状态 | ✅ | ✅ | ✅ |
| 创建备份 | ❌ | ✅ | ✅ |
| 归档会话 | ❌ | ❌ | ✅ |
| 迁移工作树 | ❌ | ❌ | ✅ |
| 轮转日志 | ❌ | ❌ | ✅ |
| 修剪元数据 | ❌ | ❌ | ⚠️ 仅 opt-in |
| 写文件 | ❌ | ✅ | ✅ |
| 需要关闭 Codex | ❌ | ❌ | ✅ |

## 核心参数速查

| 命令 | 用途 |
|------|------|
| `python keep_codex_fast.py` | 只读检查 |
| `python keep_codex_fast.py --details` | 显示详细信息 |
| `python keep_codex_fast.py --backup-only` | 仅备份 |
| `python keep_codex_fast.py --apply --wait-for-codex-exit` | 等待 Codex 退出后应用 |
| `python keep_codex_fast.py --apply --archive-older-than-days 10` | 归档 10 天前会话 |
| `python keep_codex_fast.py --apply --repair-thread-metadata-bloat` | 修复元数据膨胀 |
