# keep-codex-fast 入门指导

> 快速上手 keep-codex-fast，对 Codex 本地状态进行安全维护。

---

## 环境要求

- Python 3.10+（仅需标准库，无需额外依赖）
- Codex Desktop 或 CLI 已安装
- macOS / Linux / Windows

---

## 安装方式

### 方式一：作为 Codex 技能安装（推荐）

在 Codex 中输入：

```
Install the keep-codex-fast skill from https://github.com/vibeforge1111/keep-codex-fast
```

### 方式二：直接克隆

```bash
git clone https://github.com/vibeforge1111/keep-codex-fast.git
# 将 keep_codex_fast.py 复制到 Codex skills 目录
```

---

## 第一步：运行只读检查（Inspect）

**默认模式**，不写任何文件，隐私安全：

```bash
python scripts/keep_codex_fast.py
```

输出示例：

```
codex_home /Users/you/.codex
requested_mode report
effective_mode report
mode_safety read_only=true privacy=pseudonymous
active_session_count N
archived_session_count N
thread_metadata_bloat active_threads=N total_title_chars=X max_title_len=Y
stale_worktree_candidates N
log_size N MB
extended_path_candidates N
config_prune_candidates N
done
```

如需显示原始详细信息：

```bash
python scripts/keep_codex_fast.py --details
```

---

## 第二步：创建交接文档（Handoff Docs）

在归档前，为**可能继续的活跃仓库会话**创建交接文档：

```markdown
# Handoff: [仓库名] - [日期]

## 重新激活提示语
We are continuing from this handoff. Read this document first...

## 上下文
- 仓库路径：
- 分支：
- 当前目标：

## 已完成工作
-

## 涉及文件
-

## 已运行命令
-

## 已知问题
-

## 待决事项
-

## 下一步
1.
2.
3.
```

---

## 第三步：备份（Backup Only）

仅创建备份，不移动任何文件：

```bash
python scripts/keep_codex_fast.py --backup-only
```

备份保存至 `~/Documents/Codex/codex-backups/keep-codex-fast-*/`

---

## 第四步：应用维护（Apply）

确认交接文档已创建，且 Codex 已关闭后：

```bash
python scripts/keep_codex_fast.py --apply \
  --archive-older-than-days 10 \
  --worktree-older-than-days 7
```

或等待 Codex 自动退出：

```bash
python scripts/keep_codex_fast.py --apply --wait-for-codex-exit
```

---

## 第五步：验证结果

```bash
python scripts/keep_codex_fast.py
# 确认 session count、log size、worktree count 已减少
```

---

## 常见参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--archive-older-than-days` | 10 | 归档超过N天的非置顶会话 |
| `--worktree-older-than-days` | 7 | 迁移超过N天的工作树 |
| `--rotate-logs-above-mb` | 64 | 日志超过N MB时轮转 |
| `--thread-title-limit` | 120 | 标题长度阈值 |
| `--thread-preview-limit` | 240 | 预览长度阈值 |

---

## 恢复已归档内容

每次 apply 后，恢复脚本会保存在备份目录：

```bash
python backup/keep-codex-fast-*/restore-sessions.py
python backup/keep-codex-fast-*/restore-thread-metadata.py
```
