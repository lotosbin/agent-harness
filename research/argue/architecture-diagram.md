## 关键接口：AgentTaskDelegate

```ts
interface AgentTaskDelegate {
  // 发起任务，立即返回 taskId（不阻塞）
  dispatch(task: AgentTask): Promise<DispatchResult>;

  // 按 taskId 收集结果（引擎用它管理超时和淘汰）
  awaitResult(taskId: string, timeoutMs: number): Promise<Result>;
}

// 引擎通过这两个方法与任何 Agent 框架对接
// 支持：Claude Code CLI、Codex CLI、OpenAI API、自定义 SDK 等
```
