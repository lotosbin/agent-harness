## 命令速查

```bash
# 安装（方式一：Skill，推荐）
npx skills add https://github.com/onevcat/argue --skill argue

# 安装（方式二：CLI）
npm install -g @onevcat/argue-cli

# 配置
argue config init
argue config add-provider --id claude --type cli --cli-type claude --model-id sonnet --agent claude-agent

# 运行辩论
argue run --task "微服务应该用 monorepo 还是 polyrepo？"
argue run --task "审查这个 PR" --action "根据共识修复问题" --verbose

# 查看报告
argue view
```

## 输出文件说明

| 文件 | 内容 | 用途 |
|------|------|------|
| `events.jsonl` | 每步操作的流式日志 | 调试、审计、重放 |
| `result.json` | 结构化结果数据 | 程序化处理、集成 |
| `summary.md` | 人类可读结论报告 | 阅读、分享、存档 |
