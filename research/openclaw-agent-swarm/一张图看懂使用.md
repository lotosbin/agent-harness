## 关键技术组件速查

| 组件 | 用途 | 命令 |
|------|------|------|
| `git worktree` | 隔离分支，互不干扰 | `git worktree add ../branch -b name` |
| `tmux` | 管理 agent 会话，支持中途干预 | `tmux new-session -d -s name` |
| cron | 每 10 分钟自动检查 agent 状态 | `*/10 * * * *` |
| `gh` | 操作 GitHub，检查 CI 状态 | `gh pr status` |
| Telegram | 通知主人 | BotFather 获取 Token |
| Obsidian | 存储业务上下文，供编排者读取 | 自动同步 |
