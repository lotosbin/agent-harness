# OpenClaw Agent Swarm 入门指导

> 用 OpenClaw 编排 Codex/Claude Code，构建一人开发团队。

---

## 环境要求

- macOS / Linux / Windows（WSL）
- Node.js 18+
- OpenAI / Anthropic API Key
- Telegram 账号（用于通知）

---

## 安装 OpenClaw

```bash
# NPM 安装（推荐）
npm install -g openclaw

# Docker 部署
docker pull openclaw/openclaw:latest
docker run -d --name openclaw \
  -v ~/.openclaw:/root/.openclaw \
  openclaw/openclaw:latest

# 源码安装
git clone https://github.com/openclaw/openclaw.git
cd openclaw && npm install && npm run start
```

验证：
```bash
openclaw --version
```

---

## 初始化配置

```bash
openclaw onboard
```

按向导配置：
1. 选择消息平台（Telegram / 飞书 / Discord 等）
2. 配置端口（默认 18789）
3. 选择 Skill 技能包（可多选）
4. 配置 API Key
5. 启用 Hooks（日志记录、会话管理）

完成后访问 http://127.0.0.1:18789/chat

## 快速启动单人开发团队模式

### 方式一：直接使用 Claude Code（推荐 Claude Code 用户）

```bash
# 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 验证
claude --version

# 配置 API Key
export ANTHROPIC_API_KEY="sk-ant-xxxxx"

# 启动 agent（单次任务）
claude --model claude-opus-4.5 \
  --dangerously-skip-permissions \
  -p "实现一个用户登录 API，使用 Express + Prisma"
```

### 方式二：使用 OpenClaw 编排多个 Agent

将本文工作流复制给 OpenClaw：
```
"请用 OpenClaw 为我的代码库实现 Agent Swarm 设置：
1. 使用 git worktree 隔离每个任务
2. 用 tmux 管理多个编码 agent 会话
3. 设置每 10 分钟的 cron 监控检查 CI 状态
4. 配置多模型代码审查流水线
5. 实现 Telegram 通知"
```

OpenClaw 会自动读取架构，创建脚本，设置目录结构，配置 cron 监控。

## 多 Agent 并行工作流

### 创建隔离的 worktree + Agent

```bash
# 1. 创建 worktree
git worktree add ../feat-new-feature -b feat/new-feature origin/main

# 2. 安装依赖
cd ../feat-new-feature && pnpm install

# 3. 创建 tmux 会话并启动 agent
tmux new-session -d -s "cc-feature" \
  -c "/path/to/worktree" \
  "claude --model claude-opus-4.5 --dangerously-skip-permissions -p '你的任务 prompt'"

# 4. 监控 agent
tmux attach -t cc-feature

# 5. 中途干预方向
tmux send-keys -t cc-feature "Stop. Focus on the API layer first." Enter
tmux send-keys -t cc-feature "Check src/types/template.ts first." Enter
```

### 任务注册表（.clawdbot/active-tasks.json）

```json
{
  "id": "feat-new-feature",
  "tmuxSession": "cc-feature",
  "agent": "claude-code",
  "description": "User login API implementation",
  "repo": "my-project",
  "worktree": "feat-new-feature",
  "branch": "feat/new-feature",
  "startedAt": 1740268800000,
  "status": "running",
  "notifyOnComplete": true
}
```

### Cron 监控脚本（check-agents.sh）

每 10 分钟运行，检查：
- tmux 会话是否存活
- 分支是否有未合并的 PR
- CI 状态
- 失败时自动重启 agent（最多 3 次）

```bash
# crontab -e
*/10 * * * * /path/to/.clawdbot/check-agents.sh >> /var/log/agent-monitor.log 2>&1
```

## 常见问题

### Q: Agent 走错方向了？
用 `tmux send-keys` 发送干预指令，或直接修改任务注册表中的 prompt。

### Q: 内存不够用？
Mac Mini 16GB 最多 4-5 个 agent。建议升级到 128GB Mac Studio 或限制并发数。

### Q: 如何选择模型？
- Codex: 后端逻辑、复杂 bug
- Claude Code: 前端、git 操作
- Gemini: UI 设计

### Q: 没有 Telegram 能用吗？
OpenClaw 支持飞书、Discord、WhatsApp、Slack 等多种平台。
